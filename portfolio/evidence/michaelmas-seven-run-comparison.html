Supporting work sample for the STORiCORE Three-System Pipeline. Seven ways of running the same story-intake task on Chapter 1 of Michaelmas, compared April 23–29, 2026. Each column is one run; each row is something the run extracted or checked. Run 7 (highlighted) performed best in this comparison.

This compares whole workflows, not models: prompts and available project knowledge changed between runs. It shows what worked under my conditions, not a general benchmark.
